# 静态资源

| 文件 | 用途 |
| --- | --- |
| `planner.ico` | 程序和系统托盘图标 |
| `weekly-self-renewal-v3-spaced.png` | 当前内置周计划背景字稿，按四字分组留白 |
| `weekly-self-renewal-v1.png` | 较粗版本，保留作外观备选 |
| `weekly-self-renewal-v2.png` | 较细版本，保留作外观备选 |

三个书法字稿是使用 imagegen 制作的视觉资源，表达「向内求真　向前求变 / 自我批评　自我革命」，并非历史人物的真实手迹。程序只嵌入 v3；自选背景和个人图片保存在被忽略的 `data/backgrounds/` 中。
