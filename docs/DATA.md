# 数据、备份与迁移

## 本地存储

默认数据目录位于 `DeskPlanner.exe` 旁边：

```text
data/
  plans.json          计划、日记和个人设置
  plans.json.bak      上一次保存的版本
  backgrounds/        自选背景图片
```

仓库忽略整个 `data/` 目录，打包脚本也不会复制它。不要强制把该目录加入 Git。

也可指定独立数据目录：

```powershell
.\DeskPlanner.exe --data-dir "D:\MyPlannerData"
```

同一数据目录只运行一个实例。自启动默认使用程序旁的 `data/`；上述自定义参数不会自动写入自启动快捷方式。

## 备份与恢复

定期备份整个 `data/` 文件夹，尤其是 `plans.json` 和背景图片。`.bak` 只有上一版，不能代替长期备份。日记「导出全部」适合留一份可直接阅读的正文，但不包含计划和设置。

恢复时先退出程序，再恢复数据文件夹。JSON 损坏时程序会尝试加载备份并提示；保存恢复结果前会另存损坏原件。

程序检测到文件被外部修改时会阻止覆盖。此时请先保留编辑中的文字，重新打开程序读取最新文件。

## 更新和移动

更新程序时退出小组件，替换 `DeskPlanner.exe`，保留原来的 `data/`。移动到另一台电脑时一起复制程序和数据目录。

个人设置中的背景路径可能是绝对路径；移动后如背景无法读取，在外观设置里重新选择数据目录中的图片即可。自启动快捷方式需要在新位置重新启用。

## 格式与容量

当前 JSON 格式版本为 2，包含 `Tasks`、`Settings` 和 `Journal`。旧版没有任务类型或日记字段的文件可以自动读取。建议使用当前版本继续编辑，避免旧程序丢失新增字段。

- 周任务进度为 0%–100%，完成状态与进度保持一致。
- 一天最多保存一篇非空日记，每篇最多 8000 个字符。
- 历史任务和日记保留在本地，不会因为日期过去而删除。
- 文件读写上限为 128 MiB；达到上限时提示并保留原文件。日记分页只限制页面显示数量，完整正文始终保留。

如果需要公开截图或演示，请使用虚构数据。源码仓库不应承担个人日记备份的用途。
