# 使用说明

解压程序包后双击 `DeskPlanner.exe`。小窗默认显示在桌面右上角，上方是每周计划，下方是每日计划，两块列表分别滚动。

## 每周计划

每周按周一到周日计算。点击「本周 / 下周 / 选周」或左右箭头切换，右侧显示整周日期范围。

点击「添加周计划」填写标题和可选备注。每个任务下面都有进度条，可点击或拖动到 0%–100%，松开后保存；方向键可微调，按 Enter 或移开焦点保存。

顶部进度为各任务进度的平均值。调到 100% 会同步勾选完成，向回调会恢复未完成；直接勾选设为 100%，撤销勾选回到 0%。修改备注或调整到其他周会保留进度。

## 每日计划

点击「今天 / 明天 / 选日期」或左右箭头查看安排，点击「添加日计划」新增任务。

圆形按钮用来完成或撤销任务，完成项显示为绿色并排到列表末尾。点击标题或「编辑」修改内容、备注和日期，「⋯」菜单可移动日期或删除。删除前会确认。

每日计划和每周计划可以在编辑窗口中相互转换。转换为每日计划后不保留周任务的百分比进度。

日期在跨天、重新激活窗口和睡眠恢复时更新。过去的记录仍保留，未完成计划会显示为提示，不会自动删除。

## 每日小记

每日日期栏右侧的「日记」打开记录页。默认打开该区块当前选中的日期。

- 左侧只列出有内容的日期，每页 8 篇，按日期从新到旧排列。
- 搜索支持完整正文和日期，可按月份筛选。
- 点击记录或「打开」，右侧显示完整内容；日期选择器可以补写过去的日期。
- 点击「保存小记」或按 `Ctrl + Enter` 保存。切换日期、关闭记录页也会保存当前草稿。
- 每天保存一篇，每篇最多 8000 个字符。空白内容不保留记录，「删除这篇」会确认。
- 「导出全部」按日期从旧到新导出完整正文，支持 UTF-8 Markdown 或文本；筛选条件不会缩小导出范围。

## 外观与窗口

在「设置 → 外观设置」中修改标题、日期标签和周计划背景文字，选择 PNG、JPEG 或 BMP 背景图片，调整深浅。自选图片复制到本地数据目录。

周计划背景文字省略标点，分号用于分成两行。内置手写字稿对应「向内求真　向前求变 / 自我批评　自我革命」，其他内容使用系统字体。

拖动标题栏移动窗口，拖动右下角调整大小。窗口会避开任务栏区域。点击「◇ / ◆」切换置顶；非置顶模式可能被其他应用覆盖。

小组件不显示任务栏按钮，也不出现在 Alt + Tab 中。点击「—」或按 Esc 收起到系统托盘，双击托盘图标恢复。点击「×」退出程序；已启用的登录自启动仍然保留。

## 快捷键与自启动

| 操作 | 快捷键 |
| --- | --- |
| 添加日计划 | `Ctrl + N` |
| 添加周计划 | `Ctrl + Shift + N` |
| 保存计划编辑 / 日记 | `Ctrl + Enter` |
| 收起主窗口 | `Esc` |

推荐通过程序设置启用或关闭登录自启动。也可以在程序目录的 Windows PowerShell 中运行：

```powershell
.\install-startup.ps1
.\install-startup.ps1 -Disable
```

辅助脚本只管理当前用户启动目录中的 `每日计划.lnk`，无需管理员权限。移动程序前先关闭自启动，移动后重新启用。

记录备份、恢复与迁移见 [数据说明](DATA.md)。
